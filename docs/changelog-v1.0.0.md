# Open Design v1.0.0 版本更新说明

> 发布日期：2026-06-13
> 涵盖周期：2026-06-05 ~ 2026-06-13
> 备注：首个正式发布版本，包含 v1.0.0 发布提交（macOS 窗口拖拽、编辑画布稳定性、元素编辑增强）

---

## ✨ 新功能

### 📁 文件管理

- **文件复制**：支持在项目内复制文件，自动生成数字后缀命名（如 `copy-1.html`），CLI、前端面板和 Web 端全链路支持
- **文件夹管理**：新增子文件夹创建、文件夹内联重命名（替代原生 prompt）、批量移动文件对话框
- **文件显示别名**：支持在不修改实际文件路径的情况下设置显示名称，别名持久化到项目侧 `.open-design/aliases.json`，跟随文件夹迁移
- **文件批量选择**：侧边栏支持多文件批量选择操作

### 🎨 手动编辑模式

- **元素移动与对齐**：支持通过拖拽移动元素，新增左/右/上/下/居中对齐功能
- **批量样式编辑**：支持批量设置选中元素的样式属性
- **表格编辑支持**：扩展可编辑元素选择器，支持 `table`/`td`/`th` 等表格元素的内联编辑
- **渐变编辑器**：新增背景渐变编辑器，支持线性/径向渐变配置
- **代码查看器**：新增带搜索功能的可编辑代码查看器组件（CodeMirror 6）
- **撤销/重做**：新增 Ctrl+Z / Ctrl+Shift+Z 快捷键支持
- **画布缩放与平移**：支持滚轮缩放和中键平移画布视图
- **删除快捷键**：新增 Delete/Backspace 快捷键删除选中编辑元素，删除操作持久化到 DOM
- **链接与图片编辑**：支持直接编辑链接的文本和 href、图片的 src 和 alt 属性
- **画布稳定性**：编辑 iframe 在样式、画布尺寸、属性后台保存期间保持稳定不闪烁；文件被外部工具修改时自动刷新

### 🖥️ 桌面端体验

- **侧边标签栏**：新增侧边标签栏，支持在聊天面板与编辑面板之间切换
- **编辑面板 Portal**：编辑面板内容通过 Portal 挂载到外部宿主，优化布局隔离
- **标签页右键菜单**：工作区标签页支持右键菜单，可关闭右侧/其他/所有标签页
- **全屏状态适配**：新增桌面全屏状态监听与样式适配
- **macOS 窗口拖拽**：为红绿灯按钮右侧空白区域添加可拖拽条（`-webkit-app-region: drag`），全屏时自动隐藏
- **视口自动缩放**：重构桌面端编辑视口自动适配逻辑，使用 CSS 缩放+居中替代拉伸方案，保证渲染清晰度

### 🌐 多语言与国际化

- 新增文件夹操作、标签页、编辑属性等多组国际化翻译词条（覆盖全部 18 种语言）
- 完善手动编辑属性面板的多语言文案

### 📋 其他

- **插件模板更新**：刷新 HyperFrames 视频模板
- **Landing Page**：新增 21 个支持的 Agent 设计页面

## 🐛 Bug 修复

- **编辑选择回调**：修复编辑选择变更回调重复触发的问题，避免无效更新
- **表格选中边框**：修复表格元素选中时的边框显示问题，改用内阴影替代 outline
- **聊天历史菜单**：修复聊天历史菜单宽度与定位问题
- **截图工具**：修复截图时误抓取 hover tooltip 的问题
- **PDF 导出**：修复取消 PDF 导出时仍弹出 toast 提示的问题
- **新建项目**：修复设计系统下拉框被表单区域遮挡的问题
- **设计系统草稿**：修复草稿设计系统在新建项目中未正确处理的问题
- **接口错误处理**：兼容字符串格式的错误信息返回
- **AMR 安装**：修复 AMR 安装 URL 元数据错误
- **Passive 地址**：修复 passive address URL 末尾斜杠未清理的问题
- **桌面更新器**：限制空闲状态下的更新轮询频率
- **指标收集**：默认开启匿名指标收集，自动生成 installationId
- **打包闪退**：修复从 Finder 启动时 EPIPE 异常导致应用闪退的问题

## 🔧 重构与优化

- **编辑预览布局**：重构桌面端编辑预览布局与交互体验
- **工作区面板**：重构侧边工作区面板，分离编辑与聊天视图
- **预览缩放逻辑**：重构预览视口缩放逻辑，统一桌面与移动端的缩放适配算法
- **快捷键绑定**：修复并重构快捷键绑定逻辑
- **属性面板**：重构属性面板停靠布局，适配编辑模式工作区
- **样式优化**：优化侧边标签页与激活按钮的配色样式、编辑选中元素样式
- **构建配置**：添加缺失的 TypeScript 类型引入与构建配置
